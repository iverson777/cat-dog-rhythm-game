The Story

創作故事

班機延誤，在函館機場等飛機的午後。
Celia 最近迷上了吉伊卡哇（ちいかわ），走到哪唱到哪。她也很愛玩湯姆熊那種節奏遊戲機台。 「爸爸，我們來做一個節奏遊戲好不好？」 於是，一張紙、一支筆、一台筆電，父女倆的即興創作就這樣開始了。
Celia 負責畫角色 — 一隻虎斑喵和一隻橘喵；爸爸負責用 AI 把手繪變成遊戲角色，再用 Claude Code 寫出整個遊戲。

不到一個下午，一款有投幣、選歌、打節拍、放 MP3 真實音樂的完整節奏遊戲就誕生了。
靈感來源 — Celia 平常最愛玩的節奏遊戲機台
成果 — Celia 在函館機場試玩喵狗節奏大師

Tech Stack

技術細節

純前端實作，不依賴任何框架，用瀏覽器就能玩。

HTML / CSS / JS Web Audio API requestAnimationFrame CSS Animations MP3 節拍偵測 Sprite 序列動畫 Claude Code Nano Banana

合成器旋律使用 Web Audio API 即時生成。吉伊卡哇兩首歌使用 MP3 播放，透過能量分析演算法自動偵測節拍生成 beatmap。角色動畫由 8 幀序列圖驅動，打擊時觸發反應動畫和粒子特效。
